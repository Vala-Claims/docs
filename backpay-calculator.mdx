## Overview

The **Backpay Calculator** provides a worksheet for estimating disability backpay. Its results are estimates for review, not an official award or a determination of entitlement or fees.

## When to use

Explore an estimate using known ratings and dates, or compare worksheet scenarios before professional review.

## Prerequisites

- Access to **Resources > Backpay Calculator**
- Verified rating, date, and dependent information for the scenario
- A representative who can review the assumptions and results before use

## Step-by-step

1. Open **Resources > Backpay Calculator**. It starts with an example scenario, so replace the example values before using the results.
2. Review the previous and new rating worksheets. Enter or correct the condition rows and the applicable ratings for each scenario.
3. Check the effective date, retroactive end date, dependent information, and fee input shown in the worksheet. Use verified information; the calculator does not decide which facts or fees legally apply.
4. If **Client conditions** is available, select a Client to import conditions, then check every imported row. Editing this worksheet does not update the Client's Conditions tab. Community Edition uses manual worksheet entry instead of Client-condition import.
5. Select **Calculate** and review the displayed estimate and breakdown. Valid input changes also refresh the estimate; recheck the result after changing a value.
6. Use **Reset to Example** only to restore the sample scenario. Check all inputs again before preparing another estimate.

## Best practices

- Review the dates, dependency assumptions, rating rows, and fee input together with the result.
- Keep the calculation distinct from recorded awards or payments.
- Have an accredited representative verify the relevant facts, applicable rules, and any fee before relying on or sharing an estimate.

## Common mistakes

- Using the prefilled example as if it were a Client's calculation
- Treating an estimate as an official VA decision or payment promise
- Assuming worksheet edits change the underlying Client record
- Relying on a result without reviewing the inputs and disclaimer
