## Overview

Use **Templates > Messages** to prepare reusable message content. Saving a template and sending a message are separate actions.

## When to use

Prepare repeatable messages that your team can review and adapt, such as an intake welcome or a request for information.

## Prerequisites

- Access to **Templates > Messages** in the correct organization
- Permission to make the intended change in a writable organization
- Approved wording and a clear intended audience

## Step-by-step

1. Open **Templates > Messages**. This is the reusable-content workspace, separate from the **Messages** conversation workspace.
2. Select **New Template**. In an empty list, you can also use **Create Template**.
3. Fill in **Template Name**, **Subject**, and **Body**.
4. If you use variables, insert the available choices and check their meaning. Use **Preview** to review the message; template previews use sample data.
5. Select **Create**, or **Update** when editing an existing template.
6. Open the saved template to preview it again. Before using it for an actual message, confirm the recipients, resolved values, links, and attachments in that sending workflow.

## Best practices

- Name templates so colleagues can recognize their purpose.
- Keep reusable content free of another veteran's details.
- Treat sample preview values as examples and review the actual message before sending.
- If you need organization document attachments, save the template first, then edit it to attach the approved files.

## Common mistakes

- Assuming saving a template sends it
- Mistaking sample preview data for a recipient's information
- Confusing **Templates > Messages** with the conversation workspace
- Reusing wording or attachments without reviewing the intended audience
