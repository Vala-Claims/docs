## Overview

**Templates > Documents** stores reusable organization files. It is separate from the documents on an individual Client record and from the research **Library** under **Resources**.

## When to use

Store approved documents your team reuses across Client workflows, such as a representation agreement or an intake packet.

## Prerequisites

- Access to the correct organization's **Templates** workspace
- A writable organization and permission for the change you need
- An approved source file without another veteran's case information

## Step-by-step

1. Open **Templates**, then **Documents**.
2. Browse **Folders** or use search to find an existing file. On a phone, select **Browse** to open the navigation.
3. Select the destination folder before adding a file. Use **Upload document** for a file or **Multi-doc PDF** for a PDF that needs splitting.
4. Open the uploaded document to check its contents. Use the document menu to rename it, add tags, or select **Move to folder**.
5. Use **Actions > New folder** to create a folder when you need one. A new organization may have no folders yet.
6. Search again or reopen the folder to confirm that colleagues can find the reusable file in its intended location.

## Best practices

- Keep reusable files free of Client-specific information.
- Use folder names and tags that explain the file's intended use.
- Review a file before using it in a Client workflow. Storing it here does not complete that workflow.
- Confirm the destination and preview before importing a folder or replacing existing files.

## Common mistakes

- Looking in **Resources > Library** for organization templates
- Assuming an upload here is already attached to a Client record
- Treating collections such as **VA form overrides** as ordinary folders
- Expecting to move a locked document without the required owner/admin access
