## Overview

Use **Claims** to review and organize claim work across your organization. The workspace lists the same Claim records that appear in a Client record's **Claims** tab. Use the global workspace to work across Clients, and the Client record when you need the surrounding client context.

![The Claims workspace with views, filters, a configurable table, and claims for several Clients.](/images/claims/list.png)

## Use views to focus your work

The left-side views are **All Claims**, **Open**, **Assigned to me**, **Ready to Review**, **Pending Evidence**, **Pending Decision**, **Submitted**, and **Closed**. Select a view to focus the table on that stage of work.

Search by claim or Client information, filter by tags, and use **Sort** to change the order. Select **Columns** to show or hide standard and configured custom-field columns, then reset the table layout when you want to return to its saved starting arrangement.

The table can include Client, Conditions, Category, Claim Number, Docket Number, Lane, Days Open, Current Lane Age, Assigned to, Filing Date, Decision Date, Appeal Deadline, ITF Expiration, Status, Portal Status, Tags, Tasks, Comments, and configured custom fields. Your organization can expose a different set of columns.

Some table fields can be edited directly when you have access, including Category, Claim Number, Docket Number, Lane, Assigned to, dates, Status, and Portal Status. Open the Claim record for the full workspace.

When you select one Claim, you can use **Quick view**, **Open record**, or **Edit**. Selecting one or more Claims also makes **Delete** available. Confirm that the selected records are the intended ones before using a selection action.

## Understand Status and Review lane

**Status** describes the current work state for a Claim. Current values include **Ready to Review**, **Pending Evidence**, **Pending Decision**, **Submitted**, and **Closed**.

**Review lane** is a separate classification used for Compensation claims. The available lanes are **New**, **Supplemental**, **Increase**, **Higher Level Review**, **CUE**, **CAVC**, **TDIU**, **SMC**, and **Board Appeal**. A Review lane does not replace Status. For non-Compensation categories, the same Compensation lane choices do not apply in the same way.

## Create a Claim

Select **Add Claim** from the global workspace, or open a Client record and use its **Claims** tab to start with that Client already selected.

<Steps>
  <Step title="Choose the Client">A Client is required. Select an existing Client, or start **Add Client** when it is available and you need to create the Client first.</Step>
  <Step title="Choose the Claim category">A Claim category is required. Current categories are **Compensation (Disability)**, **Pension**, **Dependency & Survivor**, **Education**, **Housing & Loan**, **Healthcare**, **Burial & Memorial**, **Insurance**, and **Administrative / Other**.</Step>
  <Step title="Complete category-specific fields">For Compensation, choose a Review lane and link at least one Condition. For a Board Appeal, select the applicable subtype.</Step>
  <Step title="Add optional context">Add an appeal deadline, docket number, tags, or workspace custom fields when they apply, then select **Create Claim**.</Step>
</Steps>

![The Create New Claim dialog with a Client, category, review lane, dates, Conditions, and tags.](/images/claims/create-claim.png)

## Quick view or open the full record

Select a Claim to open **Quick view** for a compact summary of its details, status, assignment, and dates. Choose **Open full claim record** when you need to prepare or review the work in depth.

![Quick view for a Claim record, with claim details and an option to open the full record.](/images/claims/quick-view.png)

## Work from a Client record

The **Claims** tab in a Client record only shows that Client's claims. It does not create a second copy of the Claim. Changes you make there are reflected in the global Claims workspace and vice versa.
