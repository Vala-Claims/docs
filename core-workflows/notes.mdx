## Overview

Use **Notes** to record an interaction or follow-up. You can keep a note unlinked or associate it with a Client, claim, or contact.

## When to use

Record what happened, the event date, and what your team should review next. Use a task when you need to assign work rather than relying on a note alone.

## Prerequisites

- Access to the correct organization and any record you want to link
- Permission to create or edit notes in a writable organization

## Step-by-step

1. Open **Notes** from the navigation and select **New note**. On a phone, the button may show **New**.
2. Enter the **Note** body and an optional **Title**. If you use a note template, review and replace its example text.
3. Check **Event date & time**. This describes when the interaction happened, which may differ from when you enter it.
4. Select the relevant **Client**, **Claim**, or **Contact** if the note belongs to a record. A note has only one association. Choosing a claim links it to that claim rather than directly to the Client.
5. Add tags or pin the note if useful. **Communication type** describes the interaction; selecting **Internal note** does not make the note private.
6. Select **Create note**. To correct an existing note, open its edit action and select **Save changes**.
7. Use **Search notes** and the Client, contact, or tag filters to find it again. On a phone, open **Filters** to reach the selectors.

## Best practices

- Check the association before saving. Linked notes are shared with team members who have access; an unlinked note is personal, with owner/admin access also available.
- Separate observations from conclusions and review copied or dictated text before saving.
- Use **Templates > Notes** to maintain reusable note content, then review it for each use.

## Common mistakes

- Treating **Internal note** as a visibility control
- Linking a note to the wrong record
- Confusing the event date with the time the note was entered
- Assuming that applying a template saves a note automatically
