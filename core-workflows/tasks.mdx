## Overview

Tasks help teams keep follow-up work visible and connected to the relevant Vala workflow.

## When to use

Use Tasks for work that needs a clear next action, owner, or follow-up point.

## Prerequisites

- Access to the relevant organization and matter
- Your team's task-management conventions

## From a Client record

Use the **Tasks** tab in a Client record for follow-up work scoped to that Client. You can review active and completed work, create or edit a task, assign it, set priority, status, and a due date, and use a checklist when it is available. Client reminders can help with client-specific timing; standalone reminders and task-linked reminders are available where supported.

Use the global **Tasks** workspace when you need to review work across multiple Clients.

## Best practices

- Use action-oriented task titles.
- Include enough context to complete the work.
- Keep task status current.

## Common mistakes

- Creating vague tasks
- Omitting the Client or matter context
- Marking work complete before verification
