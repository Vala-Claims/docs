## Overview

Workflows support repeatable work in Vala. Exact triggers, actions, and availability depend on the configured product experience.

## When to use

Use Workflows when your organization has an approved repeatable workflow that should run consistently.

## Prerequisites

- Administrative or workflow access as required
- A clearly defined process
- Approval from the appropriate organization owner

## Step-by-step

<Note>
  Configuration instructions will be added after supported triggers, actions, and permissions are confirmed.
</Note>

## Workflow views

Use <strong>Active</strong> for workflows in use, <strong>Draft</strong> for work not yet active, and <strong>History</strong> to review workflow activity.

## Best practices

- Start with a narrow, reviewable scope.
- Keep a human review step for consequential outputs.
- Recheck workflows when your process changes.

## Common mistakes

- Enabling an untested workflow broadly
- Using unclear triggering criteria
- Failing to review automated results
